# NewTexPDF Studio

Una suite moderna para compilar documentos **TeX / LaTeX directamente a PDF nativo** y **exportar a Word (.docx)** con previsualización en vivo en **KaTeX**.

---

## Características

1. **Compilación PDF de Alta Precisión**:
   - Genera documentos PDF vectoriales con cálculo milimétrico de márgenes, tablas ajustadas y tipografía académica.
2. **Exportación Nativa a Word (.docx)**:
   - Convierte el contenido LaTeX a formato editable de Microsoft Word con alineaciones, tablas, estilos y membretes intactos.
3. **Previsualización KaTeX Reactiva**:
   - Renderizado en vivo mientras se redacta en el editor.
   - Vista adaptable para lectura cómoda en teléfonos móviles y simulación a escala de hoja impresa (Carta, A4, Oficio).
4. **Diseño Responsive**:
   - Menú lateral y barra de herramientas compacta con diseño limpio y modo oscuro.

---

## Despliegue en GitHub Pages / Vercel

El proyecto incluye:
- Workflow de **GitHub Actions** en `.github/workflows/deploy.yml` para despliegue automático.
- Configuración para **Vercel** en `vercel.json`.
- Rutas optimizadas en `vite.config.ts`.
